2026-10-18. 검토 기준 원격 8b53bdd 및 CR-0002 개선 코드. 코드·재현 테스트·기존 검증 기록을 근거로 한 재검토이며, 외부 금융/보안 인증이나 수익성 검증을 뜻하지 않습니다.

**판정: 연구/운영 기반 개발 중. 실제 자금으로 자동 거래할 준비는 미완료.** 현재 변경은 중요한 결함과 운영 공백을 보완하지만 실제 AI·백테스트·브로커·계좌/한도·대상 호스트 수용이 남아 있습니다. `/ops/readiness`에서도 live_trading_ready는 false를 유지합니다.

## 좋은 점

- 수집, 품질 검수, 지식 출처, 모델, 위험, 실행 모듈이 분리되어 있고 LLM 제안을 주문 권한과 구분한 설계가 있습니다.
- 비밀/원자료를 Git에서 제외하고 출처·권한·이용 가능 시점·파일 해시·정정 체인과 스냅샷을 기록합니다. 데이터 실패의 격리와 네트워크 없는 재생 경로도 있습니다.
- Decimal 금액 계산, 다음 시점 체결, 제한 재시도·중복 방지·호출 예약과 오류 시 보류를 테스트합니다. 기본 설정으로 외부 모델·실제 주문이 켜지지 않습니다.
- WBS·변경요청·불변 기준선·증거와 CI가 있습니다. 작은 모듈 구조여서 실패 경계를 구체적으로 개선할 수 있습니다.

이 강점은 안전한 출발점이며 전략의 유효성이나 전체 운영 안정성이 입증됐다는 뜻은 아닙니다.

## 현재 어느 수준인가

데이터/지식 단계의 소규모 연구 연결 검증은 기록되어 있습니다. 모델은 offline_fixture, 의견 취합과 위험/체결 데모는 합성 규칙입니다. 실제 투자 분석·토론·연속 회계·역사적 성과·외부 모의계좌·실계좌 운용으로 이어진 시스템은 아직 아닙니다. 연구용 Yahoo 자료의 가격/기업행위 의미와 운영 이용권·PIT는 별도 확인이 필요합니다.

지식 파서/청크는 v2로 갱신했습니다. v1 스냅샷은 보존하지만 현재 검색에서 거부하며 고정 원문으로 재색인해야 합니다. 기존 기록은 당시 코드/판본의 결과로 유지하고 새 품질을 소급 인증하지 않습니다. 해시는 신뢰된 ID와 파일의 일치를 검사하며 전자서명이나 자료 작성자의 인증을 제공하지 않습니다.

## 실제 트레이딩까지 필요한 경로

1. **공통 운영 수용 0.6:** 집 Windows PC에서 설치·인증·시작/재시작·절전/단절·예약 누락·외부 경보·백업 복원을 검증.
2. **AI 3.x:** 공급자·모델·월 예산 결정, 제한된 실제 호출·요청/응답/사용량 검증, 구조화된 주장/계산/인용·반론·PM·독립 위험 계약과 실패 보류.
3. **역사적 연구 4.x:** PIT·기업행위·당시 종목군, 연속 현금/포지션·매수/매도 회계, 비용·지연·비교군·표본 외 검증. 성과·손실 기준은 실험 전에 정함.
4. **브로커 모의 5.x:** 계좌·주문 식별자·불확실한 전송 조회·부분 체결/취소·잔고 대사·동시/재시작·손실 차단·관찰 기간. 브로커의 실제 지원/모의 환경과 이용 조건을 확인.
5. **실거래 6.x:** 명의자/운영자 권한, 실제 투자금·손실 한도·승인 정책을 확정하고 별도 진입 승인 후 제한 규모·수동 승인으로 관찰.

단계가 끝나기 전에 같은 코드에 live 플래그만 추가하는 방식으로 실거래를 활성화하지 않습니다. 운영 모드 prod는 먼저 연구 작업의 안정적 실행에 사용합니다.
