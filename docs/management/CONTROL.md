# 프로젝트 기준선과 변경관리

2026-10-15 사용자가 요청한 WBS 방식의 관리 규칙입니다. 원래 목표인 미국 주식·ETF, 일봉, RAG 기반 철학별 분석·토론, 독립 위험관리, 백테스트 → 브로커 모의매매 → 제한적 실거래 순서를 유지합니다.

## 기준선

- `plan-v1.0.0`: 최초 설계·운용 설계·의사결정을 `docs/baselines/v1.0`에 원문과 SHA-256으로 보존한 Git 태그. 초기 개발 코드도 같은 커밋에 보존합니다.
- `plan-v1.1.0`: CR-0001로 승인 범위 안의 데이터 MVP와 끝까지의 WBS를 구체화한 기준선. `docs/baselines/v1.1/wbs.toml`과 해시를 보존합니다.
- `plan-v1.2.0`: CR-0002 운영 기반 0.3–0.6과 선행 게이트/일정을 담은 `docs/baselines/v1.2/wbs.toml`·해시. 태그/원격 게시 결과는 최신 검증 기록에서 구분합니다.
- `plan-v1.3.0`: CR-0003의 지표·원천·시점·Agent 입력 선행 작업 1.9–1.19와 재예측 일정. `docs/baselines/v1.3/wbs.toml`·해시 보존. 기존 태그는 재작성하지 않으며 로컬/원격 태그 게시 여부를 인계 기록에서 구분한다.
- `docs/PROJECT_PLAN.md`: 현재 유효한 설계. 기준선 스냅샷을 수정하지 않고 현재 문서와 비교합니다.
- `docs/management/wbs.toml`: 작업의 단일 관리 원본. `docs/WBS.md`는 생성 결과입니다.

일정은 D+n의 상대 작업일과 예상 작업량으로 관리합니다. 선행 의존성과 예상 작업량에 따른 추정이며 약속된 달력 마감일이 아닙니다. 외부 접근·구매·LLM 선택·계좌·투자금·실거래 승인, 전향 관찰 기간이 미정이므로 확정 납기를 꾸며 쓰지 않습니다. 기준 일정은 보존하고 실제 완료일과 차단 사유를 따로 기록합니다. 일정 변경이 필요하면 영향과 새 예측을 CR에 기록합니다.

## 매 작업의 절차

1. 작업 시작 전에 현재 설계·WBS·최근 STATUS와 미해결 차단 항목을 읽습니다. 선행 게이트를 확인하고 이번 WBS ID를 정합니다.
2. 결과·검증·남은 제한을 증거 문서/테스트와 연결합니다. `done`은 선행 작업 완료 + 완료일 + 실제 증거가 있을 때만 가능합니다. 구현과 실제 외부 연결은 별도 작업입니다.
3. WBS 상태와 STATUS를 함께 갱신합니다. 단순 진행 갱신은 계획 버전을 바꾸지 않습니다. 차단된 작업은 분모에서 빼거나 다른 작업으로 조용히 대체하지 않습니다.
4. `uv run --frozen python scripts/project_status.py --write` 후 `bash scripts/check.sh`로 일관성을 확인합니다. 외부 서비스 검증은 오프라인 테스트 결과와 구분합니다.
5. `feat(data): ... [WBS 1.2–1.5]`처럼 작업 ID를 넣어 커밋합니다. 원격 반영이 실패하면 로컬 커밋/태그와 원격 상태를 구분해 보고합니다. 강제 푸시·히스토리 재작성은 하지 않습니다.

## 변경요청

범위·순서·책임·완료 기준·기준 일정이 바뀌면 `docs/changes/CR-NNNN.md`를 먼저 작성합니다. 배경, 기존/변경 내용, 대안, 영향 WBS, 비용·일정·검증 영향, 결정 근거, 새 버전을 기록합니다.

- patch: 오타·설명 정정 등 완료 기준에 영향 없는 문서 수정.
- minor: 기존 목표 안의 역할/산출물 구체화나 단계 내부 추가. 사용자 지시와 승인 범위 안의 일상 구현 선택은 계속 진행합니다.
- major: 시장·운용 주기·투자 권한·단계 게이트 등 목표의 변경. 필요한 사용자 결정을 얻고 구 기준선을 남긴 뒤 새 기준선으로 진행합니다.

기존 기준선 파일이나 태그는 덮어쓰지 않습니다. 새로운 버전은 새 디렉터리·해시·CR·태그로 생성합니다. 통과하지 않은 검증을 통과로 바꾸거나 목표 수익/품질 기준을 결과를 본 뒤 낮추지 않습니다.

Git 버전은 자동 배포·실거래 승인을 뜻하지 않습니다. 실행 결과 원본·개인 연락 주소·비밀·시장 데이터는 Git에 올리지 않고, 민감 정보가 없는 요약·검증 근거만 남깁니다.
