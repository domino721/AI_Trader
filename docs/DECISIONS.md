# 의사결정 기록

## 사용자와 확정한 범위

2026-10-15, 한국 시간 기준 대화에서 확정했습니다.

- 첫 시장: 미국 주식·ETF.
- 주기: 일봉 분석, 일간/주간 리밸런싱. 실시간 초단타는 초기 범위에 포함하지 않음.
- 단계: 백테스트 → 모의매매 → 실거래.
- 지식 활용: RAG 검색·인용 + 투자 철학별 지침. 검증 뒤 필요하면 파인튜닝.
- 자료: 공개 논문·공시와 직접 정리한 투자 원칙부터.
- 목표: 가치·모멘텀·퀀트 관점이 토론하여 투자 의사결정을 만들고 궁극적으로 자동 실행.

## 초기 설계를 위한 가정 — 최종 투자 설정이 아님

- 개인 연구용, 현금 계좌, 매수·현금 보유부터. 공매도·신용·옵션은 후속 범위.
- 초기 샘플의 USD 10,000은 가상 숫자. 실제 투자금으로 합의한 값이 아님.
- 샘플 한도: 종목당 10%, 총 투자 80%, 현금 20% 이상, 리밸런싱당 절대 비중 변화 합계 20% 이하. 연구 시작값이며 실제 운영 승인을 뜻하지 않음.
- 샘플 비용: 수수료 10bp + 매수 슬리피지 5bp. 실제 브로커·유동성 비용 모델은 나중에 정함.
- API/CLI 우선. 토론과 성과를 보는 웹 대시보드는 데이터·평가 기반 이후 개발.
- 단일 머신·단일 사용자 기준. 서비스 분리와 PostgreSQL은 운영 규모가 요구할 때 도입.

## 해당 단계 착수 전에 함께 정할 항목

| 결정 | 결정이 필요한 시점 | 검토 기준 |
| --- | --- | --- |
| 최초 종목군·벤치마크 | 실제 데이터 백테스트 전 | ETF로 실행 검증 + 재무정보가 있는 주식으로 가치 관점 검증, 당시 편입·상장폐지 포함 가능 여부 |
| 데이터 공급자·기간·예산 | 데이터 어댑터 개발 전 | point-in-time 공시, 수정주가/원주가, 상장폐지, 재배포 권한 |
| LLM 공급자·모델·월 비용 | RAG/토론 연결 전 | JSON 출력, 인용 충실도, 언어, 재현성, 호출 비용·속도 |
| 이용할 공개 문헌 목록 | 수집 단계 | 원문 이용 조건·판본·저자·일자·적용 한계 |
| 투자금·낙폭/손실 한도·실거래 승인 방식 | 브로커 모의매매 설계 전 | 감내 가능한 손실, 주문 규모, 알림·승인·중지·복구 |
| 브로커·계좌 | 외부 모의매매 연결 전 | 미국 주식 이용 자격, API/모의계좌, 주문·체결 조회, 수수료 |

아직 API 키나 유료 데이터 구매가 필요하지 않습니다. 위 결정은 오프라인 환경 준비를 막지 않습니다. 향후 필요한 비밀은 환경 설정으로 입력하고 채팅·저장소에는 남기지 않습니다.

## 추가 설계 제안 — 사용자 확정 사항과 구분

2026-10-15 데이터·역할·뉴스에 관한 사용자 질문을 검토하여 [운용 설계](OPERATING_MODEL.md)에 다음을 제안했습니다. 공급자·비용·세부 운영 정책에 관한 사용자 승인을 뜻하지 않습니다.

- 투자 분석 앞에 수집과 독립 검수·격리·시점 고정 스냅샷을 둠. 필수 데이터 실패 시 영향 범위의 신규 위험 증가를 보류.
- 세 분석 관점만의 다수결 대신 PM·독립 위험·실행/운영·독립 연구 검증의 책임을 구분. 모든 기능에 별도 LLM을 쓰지는 않음.
- 공식 공시·기업 이벤트를 논지/위험 검토에 포함하고, 일반 뉴스·감성 피드는 비용과 추가 기여를 검증한 뒤 확대.
- 데이터 수집·검수의 실패 시나리오 검증을 실제 RAG/토론 확장보다 먼저 수행.

## 2026-10-15 추가 사용자 지시

데이터 수집·검수 MVP를 진행하고, 처음 설계를 끝까지 유지하며, 필요한 수정은 저장소에서 버전별로 확인하도록 관리하라는 지시를 받았습니다. [CR-0001](changes/CR-0001.md)과 [WBS](WBS.md), Git 기준선/버전 태그로 구체화했습니다. 일상 구현은 승인 범위 안에서 진행하고, 투자 시장·주기·권한 등 목표 변경은 별도 결정으로 남깁니다.


## 2026-10-17 AI 호출 기반 구현 선택

사용자는 공급자·모델·월 예산이 미정이며 실제 모델 호출 없이 기반부터 구현하도록 선택했습니다. 모의 공급자·원자적 호출 한도/합성 비용 예약·중복 방지·실패 처리·응답 보존을 검증합니다. 유료 공급자나 금액을 임의로 확정하지 않으며 WBS 3.1의 실제 연결 완료로 취급하지 않습니다.


## 2026-10-18 실거래 준비 검토와 운영 기반

사용자는 실제 트레이딩 활용을 목표로 저장소의 강점·결함·현황을 재검토하고 필요한 개선을 진행하도록 요청했습니다. 상시 운영 후보는 집 Windows 데스크탑입니다. 토스증권 API는 후보이며 계좌 접근권한/명의자·운영자 권한, 모의 지원과 실제 연결 조건은 미확정입니다. 개인 신원·계좌 식별자·인증정보는 저장하지 않습니다.

투자금·일손실·최대낙폭과 모델/월 예산은 미정입니다. 합성 데모 기본값을 실제 한도로 사용하지 않습니다. 실제 모델 호출 없이 기반을 구현한다는 이전 선택을 유지합니다.

CR-0002로 dev/test/prod 경계·인증·readiness·영속 연구 DAG/현황판·로컬 경보·중지 상태 백업/복원을 추가합니다. 대상 PC의 설치/NTFS ACL·로그온·재부팅·절전·단절·외부 경보·복원은 별도 0.6 수용이며 이번 개발 호스트 결과로 완료하지 않습니다. prod 환경과 실거래 승인은 별개입니다. 실제 모델·역사적 검증·브로커 모의·실거래 게이트를 건너뛰지 않습니다.
