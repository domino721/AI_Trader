# 오프라인 AI 호출 기반 — WBS 3.1

2026-10-17, Asia/Seoul. 사용자는 공급자·모델·월 예산을 미정으로 두고 **실제 모델 호출 없이 기반부터 구현**하도록 선택했습니다. 이 단계에는 외부 모델 전송, SDK, 키 입력, 실제 비용 청구가 없습니다. WBS 3.1은 진행 중이며 WBS 3.2에는 착수하지 않습니다.

## 구현한 동작

`src/ai_trader/llm/`은 모의 공급자와 향후 어댑터 인터페이스를 제공합니다. 설정은 현재 `offline_fixture` / `fixture-v1`만 허용합니다. 기본 `InvocationPolicy`는 비활성화이며 월 호출 수와 예약 금액 모두 0입니다. 임의 공급자 이름으로 유료 호출을 활성화할 수 없습니다.

- 요청에는 ID, 의사결정 시각, 프롬프트 버전·과제, 지식 스냅샷/검색 결과를 보존합니다. 검색 결과의 `model_context` 목적, 동일 의사결정 시각, 근거별 이용 가능 시점과 텍스트 해시를 검사합니다. 이는 신뢰된 검색 결과와의 계약 검사이며 외부 자료의 라이선스나 진실성을 다시 인증하는 절차는 아닙니다.
- SQLite의 `BEGIN IMMEDIATE`로 시도 전에 월 호출 횟수·예약 금액을 확인하고 예약합니다. 동시 요청도 한도를 공유합니다. 월 기준은 과거 의사결정 시각이 아닌 **실제 시도 시각의 UTC 달력월**입니다.
- 예약은 보수적으로 유지합니다. 정상 응답·잘못된 응답·시간 초과 모두 예약을 소비합니다. 시도 전 실패도 예약을 돌려주지 않습니다. 현재 USD 숫자는 **합성 예약 시뮬레이션**이며 사용료·청구액·실제 공급자의 비용 상한을 뜻하지 않습니다.
- 동일 요청 ID와 동일 내용은 저장된 결과를 다시 읽고 재호출하지 않습니다. 같은 ID에 다른 내용은 거부합니다. 실행 중이거나 프로세스 종료로 결과가 불확실한 요청도 자동 재발행하지 않습니다. 정책을 변경한 새 실험에는 새 요청 ID를 사용합니다.
- 어댑터가 ‘전송 전 실패’를 명시한 경우에만 설정된 최대 시도 수 이내에서 재시도합니다. 재시도마다 별도로 예약합니다. 시간 초과나 일반 오류는 자동 재시도하지 않습니다. 어댑터에 제한 시간을 전달하며, 실제 HTTP 제한 시간·취소 동작은 외부 공급자를 고른 다음 별도로 검증해야 합니다.
- 모델 ID 불일치, JSON 구문 오류, 중복 키, 비유한 수치, 객체 이외 응답은 보류합니다. 정상 JSON도 미검증 제안일 뿐입니다. 분석가 출력 스키마·주장/인용 검토·반론·위험/주문 연결은 이 구현에 포함하지 않습니다.

원문·프롬프트·응답·사용량·정책은 Git에서 제외되는 `<state_dir>/llm/invocations.db`에 저장합니다. DB 권한은 0600입니다. 유효한 텍스트 응답은 실패한 JSON도 그대로 보존합니다. 65,536자를 넘는 응답은 원본 해시와 앞부분만 저장하고 `truncated`를 표시합니다. 잘못된 응답 봉투나 어댑터 예외의 원문은 비밀 노출을 피하기 위해 저장하지 않고 오류 코드만 남깁니다. CLI는 원문·응답·예외 메시지를 출력하지 않습니다.

문서 안 명령이나 JSON 안 거래 지시는 실행하지 않습니다. 이 모듈은 위험·실행 모듈을 호출하지 않으며 모든 결과에 `offline_only=true`, `untrusted_proposal_only=true`, `trading_approved=false`를 고정합니다.

## 재현

```bash
uv run --frozen ai-trader llm-smoke --request-id offline-smoke-v1
```

이 명령은 **합성 검색 근거와 메모리 안의 모의 응답**만 사용합니다. 실제 시장 자료·사용자 문서를 보내지 않습니다. 모의 정책은 UTC 월별 3회, 예약 합계 USD 0.03, 시도별 USD 0.01이며 실제 비용은 발생하지 않습니다. 같은 ID로 다시 실행하면 이전 결과를 반환합니다. 종료 0은 모의 응답 처리 완료, 2는 보류, 1은 잘못된 입력·저장 오류입니다. 기본 상태 경로는 `.local`이며 `AI_TRADER_STATE_DIR`로 변경할 수 있습니다.

`tests/test_llm.py`는 기본 비활성화, 실제 공급자 설정 거부, 중복·재시작·동시 실행, 원문/사용량 보존, 월 한도·월 경계, 전송 전 실패의 제한 재시도, 불확실한 시간 초과의 재발행 방지, 잘못된 JSON/모델/근거와 출력 비노출을 검증합니다. 테스트는 네트워크를 사용하지 않습니다.

## 실제 연결 전에 남은 결정과 검증

1. 공급자·고정 모델 ID·월 예산을 결정하고 이용 조건, 토큰 산정·가격표 버전·최대 출력·실패 청구 정책을 확인합니다. 현재 구현의 합성 예약액을 실제 비용 한도로 재사용하지 않습니다.
2. 선택한 공급자의 전용 어댑터와 제한 시간·응답 크기·불확실한 요청/재시도 정책을 구현하고, 권한 있는 자료만으로 실제 최소 호출·응답 보존·청구/사용량 대조를 별도 검증합니다.
3. 위 조건의 근거가 있어야 WBS 3.1을 완료합니다. 현재 모의 테스트 통과만으로 실제 LLM 연결이나 비용 통제가 검증됐다고 하지 않습니다.

이 문서의 최초 구현은 기준선 v1.1.0에서 진행했습니다. 현재 계획 v1.2.0/CR-0002는 공통 운영 선행 게이트를 추가하며 원격의 WBS 2.1–2.3 완료 기록과 3.1 오프라인 실적은 보존합니다. 실제 공급자 완료를 뜻하지 않습니다.
