# CR-0001 — 데이터 수집·검수 MVP와 WBS 기준선 구체화

- 날짜: 2026-10-15 (한국 시간)
- 버전: 설계 기준선 1.0.0 → 실행 계획 1.1.0
- 결정: 사용자의 “지금 말한 거 진행”, “처음 계획한 설계 유지”, “수정 시 버전 관리”, “WBS 일정관리” 지시에 따라 진행.
- 영향: WBS 0.2, 1.1–1.8 및 후속 단계의 추적 방식.

## 유지하는 사항

미국 주식·ETF, 일봉·일간/주간 리밸런싱, 공개 문헌 RAG, 역할별 분석·반론·PM, 독립 위험 엔진, 연구/백테스트 → 모의매매 → 제한적 실거래의 목표와 순서를 유지합니다.

## 구체화한 사항

- 주식 AAPL/MSFT/GOOGL/AMZN/JPM, ETF SPY/IWM은 수집 경로를 검증할 작은 고정 표본입니다. 추천 종목이나 당시 전체 투자 가능 종목군이 아닙니다.
- 키 없는 Yahoo chart 어댑터를 가격·조정종가·분할/배당의 개인 연구용 연결 후보로, SEC submissions를 기업 공시 목록/수락 시각의 원출처로 사용합니다. Yahoo의 장기 이용권·서비스 보장·PIT·상장폐지 품질을 확정한 것은 아닙니다. 운영 공급자 선정은 별도입니다.
- SEC는 우선 공시 **목록/메타데이터**까지 수집합니다. 공시 본문/XBRL의 파싱·단위·정정 재구성은 후속 WBS 2.1/4.1에 남깁니다. 메타데이터만으로 가치 평가가 준비됐다고 하지 않습니다.
- 수집 체크포인트, 원본/정정 보존, 가격/시점/커버리지 검수·격리, 결정적인 스냅샷과 원본에 고정된 오프라인 재생을 구현합니다.
- 거래소 캘린더 의존성을 추가합니다. 데이터 MVP가 주문이나 기존 합성 데모를 자동 실행하도록 연결하지 않습니다.
- 단계 1 전체에는 문헌/지식도 포함되어 있었으므로 데이터 MVP 완료를 단계 1 전체 완료로 쓰지 않습니다. WBS 2.x의 지식 산출물까지 추적합니다.

## 대안과 영향

처음부터 유료 공급자를 고르면 이용 조건과 이력 품질을 개선할 수 있지만 예산·계약·키가 선행됩니다. 무료 CSV만으로는 필요한 기업행위와 공시 시점을 충족하기 어렵습니다. 우선 교체 가능한 어댑터와 검수 계약을 구현하고 실제 연결 여부를 별도 게이트로 둡니다.

실제 공급자 검증에는 네트워크 허용과 SEC 연락 식별 정보가 필요합니다. 환경 초안 저장은 실행 환경 반영을 뜻하지 않습니다. 오프라인 테스트가 통과해도 외부 연결 게이트를 생략하지 않습니다. WBS 상대 일정은 1인 순차 개발 가정의 초안 추정이며 외부 관찰·사용자 결정 대기에는 재예측이 필요합니다.

## 검증·변경 기록

실행 근거는 `docs/DATA_MVP.md`, 현재 실적·차단 사유는 `docs/management/STATUS.md`, 고정된 작업 정의는 `docs/baselines/v1.1/wbs.toml`에 보존합니다. 공급자 변경은 어댑터·출처 메타데이터와 WBS 영향까지 기록하는 새 CR로 관리합니다.
