# CR-0003 — 지표·재무 원천·시점 일관성·Agent 입력 데이터 계획

- 날짜: 2026-10-18 (한국 시간). 계획 1.2.0 → 1.3.0.
- 사용자 지시: 검토한 가격/재무/위험/거시/대체 지표의 필요성·우선순위를 저장소 설계와 WBS에 남기고 다른 AI Agent가 구현을 이어갈 수 있게 커밋·게시한다.
- 이번 범위는 계획·인계 문서와 기준선 검증 등록이다. 지표 계산·외부 수집·실제 모델·주문은 구현하거나 활성화하지 않는다. 첨부 작업표의 개인 이름·담당/일정은 옮기지 않는다.

## 배경과 변경

기존 1.1–1.8 완료는 7종목 연구용 수집 MVP 표본의 증거이며 전체 재무 지표·당시 종목군·실거래 데이터 준비 완료가 아니다. 현재 수집은 가격/기업행위와 공시 메타데이터 중심이고 XBRL 재무 정규화·feature store·시장 데이터 정기 DAG가 없다. 현재 체크아웃에는 과거 시장 데이터 원본이 복원되어 있지 않다.

새 작업 1.9–1.19를 추가한다: 데이터 실물 확인/복원 → 지표·시점 계약 → 장기 가격/재무 원천 → 핵심 가격·재무 지표/공식 이벤트/맥락 → feature snapshot·품질 → 실제 데이터 DAG → Agent 입력 수용. 산식·가격/시점 정의를 수집보다 앞에 둔다. 선택 지표는 4.3의 추가 기여 비교 후 승격하며 모든 지표의 동시 구현·유료 공급자 구매를 필수로 만들지 않는다.

3.2는 기존 3.1·0.6에 데이터 수용 1.19를 추가한다. 4.1도 1.19를 명시하며 더 넓은 역사적 PIT·당시 종목군·정정/생존편향 검증 책임을 유지한다. 4.3은 핵심 대비 추가 지표·뉴스/거시의 비용 차감 기여와 중복을 검증한다. 기존 완료/차단/진행 기록은 보존한다.

## 기준선·일정·대안

`docs/baselines/v1.3/wbs.toml`·SHA-256·새 plan-v1.3.0 태그를 생성하고 등록한다. v1.0–v1.2 원문·해시·기존 태그는 수정하지 않는다. 현행 WBS의 상대 일정은 기존보다 이르지 않게 새 선행 조건을 반영해 재계산한다. D+n은 의존성 기반 예상 작업량이며 납기·관찰 기간 약속이 아니다. 데이터 권한·구매·대상 호스트·모델/예산 미정은 실제 연결 수용의 차단으로 남긴다.

대안은 기술적 지표를 모두 먼저 만들거나 데이터 완성을 AI 이후로 미루는 것이다. 전자는 중복·과최적화와 정의 충돌을 키우고 후자는 근거 없는 Agent 토의를 만들 수 있어, 작은 핵심 세트와 시점/출처 계약을 먼저 검증한다. 미국 주식/ETF·일봉·연구→백테스트→브로커 모의→별도 실거래 승인 목표는 유지한다.

## 완료 조건과 검증

이번 문서 인계의 완료는 우선순위/항목 매핑·입출력 계약·담당 모듈·실패/외부 수용 조건·다음 Agent 착수 절차·일관된 WBS/기준선/링크가 존재하는 것이다. 새 데이터 작업 11개는 모두 미착수로 남긴다. 계획 검증·기존 회귀·Git diff 검사 후 게시하며, 문서 추가를 데이터/지표 구현 완료로 표시하지 않는다.
